# Forum ENSTAB 2026 — Energy Sovereignty in Action

Official website for the 9th edition of the **Forum ENSTAB** (Energy Sovereignty in Action), taking place on **November 25, 2026** at **ENSTAB, Borj Cédria, Tunisia**, organized by **ETC Junior Entreprise**.

## Features

- **Cinematic Scrollytelling**: Interactive Earth-to-campus descent, video scrubbing, and theme revelation.
- **Programme & Calendar**: Event agenda preview and instant calendar export (`.ics`).
- **Edition 2026**: Guests of honour, eleven exhibitors, sponsors and musical collaborator, with clean in-page logo previews.
- **Registration**: Direct Volunteery registration and Google Maps directions.
- **Interactive Photo Gallery**: Highlights and moments from previous editions.

## Getting Started

### Prerequisites

- Node.js `>= 20.9.0`
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Build

```bash
npm run build
npm start
```

### Typecheck

```bash
npm run typecheck
```

## Deployment on Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Next.js**.
3. Root Directory: `./`.
4. Build Command: `npm run build`.
5. Output Directory: Default (`.next`).
